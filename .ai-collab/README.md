# AI Collaboration Workspace

This folder coordinates Codex and Claude while both work in `/Users/walesz/Desktop/WaleszDesk`.

Files:
- `TASKS.md`: current task board.
- `CLAIMS.md`: active ownership of files or areas.
- `LOG.md`: chronological agent updates.
- `DECISIONS.md`: durable decisions and assumptions.
- `status.sh`: quick shared status command.

Core rules:
- One path owner at a time.
- Claim before editing.
- Log meaningful changes.
- Release claims quickly.
- Never revert changes made by the user or the other agent.
- If there is ambiguity, stop editing and write it down.
